
# Fermi Pico Bagel Game

A Python-based number guessing game inspired by the classic Fermi Pico Bagel puzzle.

## Features

- Random number generation
- User input validation
- Fermi, Pico, and Bagel hints
- Attempts tracking

## Technologies Used

- Python 3

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Anithaayyarappan/Fermi-Pico-Bagel-game.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Fermi-Pico-Bagel-game
   ```

3. Run the Python program:

   ```bash
   python main.py
   ```

## Game Rules

- **Fermi** – A digit is correct and in the correct position.
- **Pico** – A digit is correct but in the wrong position.
- **Bagel** – No digits are correct.
